# fsoworld.com

Static marketing site for FSO (Financially Smart Organisation), generated by `build.py`.

## How it deploys
This repo is connected to Netlify. On every push to `main`, Netlify runs:

    python3 build.py

which generates the site into `public/`, and publishes that folder. No manual
upload is needed. `netlify.toml` holds the build command, caching headers and
redirects.

## Local preview
    python3 build.py
    # open public/index.html  (or: python3 -m http.server -d public 8000)

`build.py` is the single source of truth for all page content, the shared
head/header/footer, and the components. Edit it, push, and the live site updates.
